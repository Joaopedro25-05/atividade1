# Versionamento semântico:

Método utilizado para identificar cada tipo de alteração feita no projeto, a estrutura desse método se baseia em 3 números, por exemplo v1.0.0, cada um dos números representa um tipo de alteração, sendo eles MAJOR.MINOR.PATCH.

MAJOR: Usado quando as alterações no sistema são incompatíveis com a versão anterior. Alterando o número da seguinte forma: v1.0.0 -> v2.0.0.

MINOR: Usado quando as alterações são compatíveis com as versões anteriores do sistema. Alterando o número da seguinte forma: v1.0.0 -> v1.1.0.

PATCH: Usado quando as alterações são feitas para corrigir bugs das versões anteriores. Alterando o número da seguinte forma: v1.0.0 -> v1.0.1.
